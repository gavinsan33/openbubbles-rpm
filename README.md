# OpenBubbles RPM repository

dnf repository for the Linux build of [OpenBubbles](https://github.com/gavinsan33/openbubbles-app).

## Install

```sh
sudo curl -fsSL -o /etc/yum.repos.d/openbubbles.repo https://gavinsan33.github.io/openbubbles-rpm/openbubbles.repo
sudo dnf install openbubbles
```

Updates then arrive with `sudo dnf upgrade`. Launch it from your app menu, or run `openbubbles`.

Packages and repository metadata are signed with the OpenBubbles RPM signing key,
fingerprint `263D A61C D7D9 F531 226A  CABF B081 349D 8D53 05BF`; dnf asks you to confirm it
on first install.

This repository is regenerated by `linux/rpm/release.sh` in the app repository and keeps the
latest few releases only.
